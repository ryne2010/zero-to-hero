# Prompt: deep interview

Use for the first phase. Do not write app code.

```txt
Use the zero-to-hero skill.
Run the deep interview for this product/repo.

Goal: collect enough information to create an implementation-ready canonical source-of-truth repo.

Ask focused questions covering:
1. product intent, users, jobs, outcomes;
2. business/model/non-goals;
3. tech stack preferences and constraints;
4. UI/design/art direction and visual asset workflow;
5. mechanical/CAD/PCB/firmware/hardware scope if applicable;
6. data/security/privacy/compliance risks;
7. workflows, edge cases, negative paths;
8. local mode and production mode boundaries;
9. desired Codex/OMX handoff workflow;
10. unresolved decisions.

Write the interview summary to .omx/context/zero-to-hero-interview.md and .codex/reports/zero-to-hero/interview-summary.md.
Do not implement product code.
```
