# Acceptance evidence

Every generated implementation-ready repo should define what evidence proves completion.

For software products, evidence usually includes build/test output, route or API workflow tests, screenshots or traces when UI exists, runtime evidence for priority workflows, and proof that external effects are disabled in Local Mode.

For hardware products, evidence usually includes requirements, dimensions/tolerances, schematic/layout review checklists, manufacturing constraints, firmware bring-up plan, and explicit human review gates.
