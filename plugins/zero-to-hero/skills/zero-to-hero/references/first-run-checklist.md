# First-run checklist

Use this checklist before generating or modifying a target repository.

```txt
1. Confirm whether the user is starting from an idea, an existing repo, or both.
2. Confirm whether the skill may write files in the target repo.
3. Run the deep interview unless the user provides an approved interview artifact.
4. Detect capabilities before choosing output profiles.
5. Identify required source research and whether web access is available.
6. Identify safety, regulatory, hardware, privacy, or real-world-effect risks.
7. Create or update the decision ledger for explicit, inferred, unresolved, rejected, and out-of-scope decisions.
8. Generate a file manifest and change summary for every write phase.
9. Do not implement product runtime code.
10. Stop before turning inferred behavior into canonical product policy without approval.
```
