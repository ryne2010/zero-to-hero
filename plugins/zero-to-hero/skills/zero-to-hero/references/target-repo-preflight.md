# Target repo preflight

Before generating or applying artifacts, inspect the target repo for:

- existing source-of-truth docs;
- package/build/test commands;
- technology capabilities;
- existing `.omx` structure;
- existing `.agents/skills`;
- generated or archived artifacts;
- scaffold residue;
- secrets or PII risk;
- conflicting instructions.

Write findings to `.codex/reports/zero-to-hero/target-repo-preflight.md` or include them in the interview/research phase output.
