# Frontend Parity System

The Frontend Parity System converts approved visual targets into implementation contracts.

## Required artifacts


## Rule

Generated PNG/SVG/Figma screenshots are **visual evidence**, not the full spec. Every visual target must be deconstructed into regions, components, states, interactions, data requirements, and tests.

## Key gates

- no scaffold content
- screenshot evidence
- mobile/desktop coverage
- accessibility checks
- route-specific synthetic data
- UI workbench/design-system route
