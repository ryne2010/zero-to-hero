# Visual Product Spec Pack

## Flow

```txt
visual lane generation
→ user selects a direction
→ full visual pack generation
→ visual deconstruction
→ route/component/workflow contracts
→ implementation tasks
→ screenshot and Storybook/Playwright verification
```

## Visual inference ledger

Every behavior implied from a visual target must be classified:

```txt
explicit: stated in docs or visually obvious and approved
inferred: agent-derived, requires review or acceptance gate
unresolved: cannot be safely implemented without a decision
```

## Suggested visual pack

```txt
design direction board
design system board
component library board
primary desktop routes
primary mobile routes
motion system board
empty/loading/error state board
mascot/helper character board
hardware/mechanical concept board when applicable
```
